# OOP-project
Object oriented group programming project

Our program will create a grocery management system using parallel arrays. 
The system will store data about grocery items in multiple arrays, with each array representing a specific attribute of an item, 
like its name, category, quantity, and price.
The same index in each array will refer to the same grocery item.
